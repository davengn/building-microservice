## Why this lesson matters

Microservices increase the number of integration points. This lesson helps you keep tests useful without turning every release into a full-system rehearsal.

- Contract tests protect expectations between teams.
- Large end-to-end suites can become slow and fragile.
- Production telemetry complements, but does not replace, pre-release tests.

## Core study path

Read with the question: which test gives the earliest trustworthy signal for this risk?

- Use unit tests for local behavior.
- Use contract tests for boundary expectations.
- Use selective end-to-end tests for critical user journeys.

## Practice cues

Pick one service dependency and define the contract you would test. Include request shape, response meaning, failure behavior, and versioning expectations.

- Remove tests that only duplicate lower-level coverage.
- Make ownership clear when a contract breaks.
- Keep critical journeys small enough to debug.
