## Why this lesson matters

The closing material supports recall. Use it to revisit terms, find related chapters, and decide which concepts deserve another pass.

- Glossary entries are anchors for future concept pages.
- Index-style navigation helps returning readers start from a term.
- Review work should connect vocabulary to practical tradeoffs.

## Core study path

After the main chapters, scan the terms that feel fuzzy. Open their related lessons and rewrite the idea in your own system context.

- Start with terms that appear in your current work.
- Link each term to one design decision.
- Capture examples that make the vocabulary concrete.

## Practice cues

Create a personal review list from the glossary. For each term, write a definition, a risk, and a chapter link to revisit.

- Prioritize terms tied to current project decisions.
- Add a production example when possible.
- Revisit the concept after applying it once.
